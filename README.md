# ثبات · Thabat

تطبيق إنتاجية يُنظّم اليوم حول الصلوات الخمس: المواقيت والأذان، والمصحف، والورد والحفظ والمراجعة، والمؤقّت، والمهام، والتقويم، والملاحظات.
من صنع **jake750_** (فرات بوشاعة). المستودع خاص، والاستخدام وفق [LICENSE.txt](LICENSE.txt).

## البنية

- `dev/src.html`: **مصدر الحقيقة**. التطبيق كله ملف HTML واحد، وفيه مواضع تُملأ عند البناء من `dev/placeholders.json`.
- `dev/build.py`: يبني `Thabat/Thabat.html` من المصدر.
- `dev/lib.py`: أداة التعديل `P`. التعديلات تُطبَّق على `src.html` بسكربت بايثون صغير، ولا يُعدَّل الملف المبني يدوياً.
- `dev/modules/`: الوحدات التي دُمجت في المصدر، محفوظة للمرجع.
- `dev/android/`: غلاف أندرويد (Java) وسكربتات بناء APK وAAB.
- `dev/mac/`: ملف التشغيل وملف «اقرأني» لنسخة الماك.
- `CLAUDE.md`: دليل المشروع المفصّل (طريقة التعديل، الفحوص، الأخطاء المعروفة).

## البناء

```bash
python dev/build.py
```

ينتج `Thabat/Thabat.html`. لتشغيله كاملاً تحتاج مجلدَي `mushaf/` و`tafsir/` وملفات الأذان: خذها من ملف `Thabat-Windows.zip` في صفحة Releases وضعها بجانب `Thabat.html`.

النسخ الجاهزة (APK وويندوز وماك) تُنشر في صفحة **Releases**، ولا تُرفع إلى الشيفرة.

## التوقيع

مفتاح توقيع أندرويد **ليس في المستودع** ولا يُرفع أبداً. السكربتات تقرأ كلمة السر من المتغيّر `THABAT_KS_PASS`.

## طريقة العمل

1. اسحب آخر نسخة: `git pull`
2. أنشئ فرعاً لتعديلك: `git switch -c اسم-التعديل`
3. عدّل `dev/src.html` (عبر `dev/lib.py`)، ثم ابنِ وافحص.
4. ارفع الفرع وافتح Pull Request ليراجعه صاحب المشروع.
