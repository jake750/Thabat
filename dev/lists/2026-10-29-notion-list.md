# Notion list (2026-10-29) — what Notion has that Thabat lacks, 32 items

Checked against the code on 2026-10-29 (3.137.0). Already in Thabat and left out: nested folders, covers, backlinks, graph, tables, footnotes, slash menu, format bar, templates, Notion import, Markdown/Word export, print, find in note, tags + stats, smart folders, tasks kanban, trash, version-free undo, read later, share to Thabat. Rejected earlier and left out: callouts, note reminders, version history, password lock, hover preview of links, #/@ autocomplete, AI, focus writing mode, list/compact views.

Fix to do regardless: the reading view shows `>` quotes, `####`, `---`, `~~strike~~` and `*italic*` as raw text (the 3.133 «❝» button writes `> `).

## Editor and blocks
1. Code blocks ``` in a fixed-width font with a copy button
2. Foldable list ▸ inside the text (toggle)
3. Columns: two or three blocks side by side
4. A picture inside the text where it was put, not at the end of the note
5. A card for a link: title, description, picture
6. Embed YouTube, a map or a PDF page inside a note
7. Move a paragraph up/down (Alt+↑↓) and a drag handle in reading mode
8. «Turn into»: heading, list, task or quote for the line
9. Colour for the text and for a line's background
10. Maths (LaTeX)
11. A date like «@غدًا» becomes a link to that day in the calendar

## Pages
12. A note inside a note (sub-pages)
13. An icon for each note from Thabat's icons
14. Embed part of another note that stays in sync `![[note#heading]]`
15. Duplicate a note
16. Move the selected section to another note
17. «Recently opened» notes
18. A font per note: normal, naskh or fixed width
19. A live task list inside a note (tasks of one tag, done from there)
20. A button inside a note that adds a ready block in one tap

## Databases
21. Note properties: status, date, number, select, link
22. A folder as a table of properties, sorted and filtered
23. A folder as a kanban board by status
24. A folder in a calendar by its date property
25. A timeline (Gantt) for notes with two dates
26. Saved views: filter, sort and group under a name
27. Link a note to tasks and show their progress (rollup)
28. Formulas in properties
29. An input form that adds a row to a database

## Sharing and collecting
30. Publish a note as a web page with a link (through GitHub)
31. Comments on parts of a note's text
32. Save a whole article from a link as a note (the text, not only the title)

Recommended: 1, 2, 4, 7, 12, 15, 21, 22, 23.
